# HealthSync
OOP project

### Application Description	:
Balancing working out and physical health is super important when keeping your body healthy. Health Over Wealth brings fitness, nutrition, hydration and sleep management together and implements AI suggestions based off each user’s information. This allows beginners to not be overwhelmed with balancing all their information between several apps, rather, the user will be guided through it all from day one.
